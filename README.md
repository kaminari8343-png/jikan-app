# きょうのよてい（jikan-app）

小学生が、帰宅後のスケジュールを自分で並べて、音声ガイドつきで実行するための PWA です。
React + Vite + TypeScript / データは localStorage に保存。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173/jikan-app/
npm test         # 時間計算・読み上げ(かな)のテスト
npm run build
```

## まいにちの土台（がっこうの日・やすみの日）
- **がっこうの日 / やすみの日**: 月〜金は「がっこうの日」、土日と日本の祝日は「やすみの日」。祝日は `@holiday-jp/holiday_jp` のデータをアプリに同梱しているので、ネット接続なしで判定します。
  長いお休み（なつやすみ など）は、⚙️せってい →「どだいと ながい やすみ」で期間を登録できます。その日だけ手動で「やすみに する／がっこうに する」も切りかえられます（優先順位: 手動 > 長いお休み > 祝日 > 土日 > 平日）
- **土台（テンプレート）**: その日に初めて開くと、その日の土台のじこくカードが自動で並びます。
  - がっこうの日: おきる 6:30 → あさのカード（きがえ・あさごはん・はみがき・トイレ・もちものチェック）→ いえをでる 7:20 → がっこう 7:20〜15:00 → ゆうごはん 18:30〜19:00 → おふろ 19:30〜20:00 → ねる 21:00
  - やすみの日: あさごはん 7:30〜8:00、ひるごはん 12:00〜12:30、ゆうごはん、おふろ、ねる
  - ⚙️せってい →「どだいと ながい やすみ」で、時刻・カード・曜日ごとの上書き（例: 水曜はがっこう 7:20〜14:00）を親が編集できます
  - 土台を直したり長いお休みを登録しても、すでに作られた日のよていは そのままです（種類が変わったときは「どだいで つくりなおす」を案内します）
- **あした**: 「あした」タブで、次の日のよていを前の晩に立てられます（スタートは当日から）。日がかわると、作っておいたよていが「きょう」になります
- **しずか（🔕）**: オンのじこくカードは、はじまり・おわりのお知らせをしません（5分前のお知らせはします）。がっこう・ごはん・おふろが初期でオン
- **いえをでる（🚪 でかけるカード）**: 10・5・1ぷんまえに「あと◯ぷんで いえをでるよ」、時刻に「いってらっしゃい！」
- **時刻だけのカード**（おきる・いえをでる）: 長さがなく、時刻になると知らせて すぐ次へ進みます
- 過ぎた時刻のじこくカードは うすく表示。スタートより前に過ぎたブロックのカードは、記録せずに とばします（夕方にスタートしても、朝の分が「じかんぎれ」にならないように）

## 1日のスケジュール（じこくカード・じゆうじかん）
- 📌 **じこくカード**: 開始時刻が決まっているカード（ゆうごはん 6じ30ぷん・おふろ・ねる など）。⚙️せってい →「じこくカード」で、親が追加・編集・削除できます（ねる は「ながさなし」＝1日の終わり）。
  よていの中では時刻順に自動で並び、ドラッグでは動かせません（✕で外せます）
- **あいだのブロック**: スタート時刻（初期値は「いま」、−／＋で変更）から最初のじこくカードまで、じこくカードどうしのあいだが1つのブロックです。
  ふつうのカードはブロックに積み、あまった時間は自動で「🕊️じゆうじかん」になります。入りきらないときは赤く「〇〇に まにあわないよ」と出ます
- **じっこう中**: ふつうのカードが早く終わったら、じこくカードの時刻まで「じゆうじかん」。時刻になったら、実行中のカードを止めて知らせ、⭕️❌をつけます。
  そのブロックでやれなかったカードは「じかんぎれ」として記録し、次のブロックへ進みます。「+5ふん」は次のじこくカードをこえるときはできません（理由を声で伝えます）。5分前にも知らせます
- **時計**: 文字盤に、予定ごとの色の扇形を表示（実行中は、いまのカードを強調）
- **りれき・はなまる**: じこくカード・じゆうじかん・じかんぎれも記録しますが、評価なし・はなまるの判定には入りません
- 「いつものよてい」には、じこくカードとスタート時刻も保存されます
- スタート時刻を「いま」以外にしても、じっこうは「いま」からはじまります（じこくカードの時刻はそのまま）

## りれき・じぶんでふりかえり
- カードの時間が終わると「⭕️／❌」の画面になり、押すまで次のカードは始まりません（スキップしたカードも評価できます）
- 「りれき」で、月ごとのカレンダーと、日ごとの記録（時刻順）が見られます
- 花丸💮: その日をさいごまでやって全部⭕️ / 丸⭕: さいごまでやったが❌が混ざった / 印なし: とちゅうでやめた
  （1日に何回かスタートした日は、全部の回を合わせて判定。何も評価しないうちにやめた回は数えません）
- 記録は localStorage（`jikan-app:history`）に保存。⚙️せってい →「きろくを ほぞん／よみこむ」でJSONバックアップ

## こえの キャラクター
⚙️ せってい →「こえの キャラクター」で、絵文字つきの大きなボタンから選べます（それぞれ「▶ ためしにきく」で聞けます）。

| キャラ | 声 | 話し方 |
|---|---|---|
| 👩 やさしい おねえさん | 女性・高さ 1.2・速さ 0.9（これまでの声とセリフ） | 「しゅくだい、はじまるよー！じゅうごふんだよ」 |
| 👦 げんきな おにいさん | 男性・元気で少し速め | 「よーし！しゅくだい いくぞー！じゅうごふんだ！」 |
| 🤖 ロボット | 男性・低めでゆっくり | 「シュクダイ ヲ カイシ シマス。ジュウゴフン デス。ピピッ」（ぜんぶカタカナ） |
| 🥷 にんじゃ | 男性・やや低め | 語尾「〜でござる」「ニンニン」 |
| 🐱 ねこ | 女性・高め | 語尾「〜にゃ」 |
| 🎲 まいにち かわる | 日づけで決まる（同じ日は同じキャラ、つぎの日はかならず別のキャラ、5日で全員） | |

- 声は、端末の日本語の声から自動でえらびます（名前から性別をあてます）。男性の声がない端末では、女性の声の高さを下げて代用します
- 親は「こえの ちょうせい」で、キャラごとに 声・高さ・速さ を変えられます（前のバージョンの はやさ・たかさ は おねえさんの調整として引きつぎます）

## カードの読みかた（読み変換）
カードの名前は画面ではそのまま（例: ネットフリックス）ですが、読み上げは `src/readings.ts` に登録した読みかた（例: ねっとふりっくす）で話します。
読み間違いがあったら、`READINGS` に足すだけで直せます（英字の別名も登録でき、大文字小文字・全角半角はくべつしません）。
⚙️ せってい →「カードの よみかた」の ボタンで、えらんだキャラの声で聞いて確かめられます。

## セリフを変える
セリフは **キャラごとのファイル** `src/phrases/` にあります（`onee.ts` `onii.ts` `robot.ts` `ninja.ts` `neko.ts`）。書きかえるだけで、そのキャラの話し方が変わります。
`{name}` `{min}` `{next}` `{fixed}` `{time}` が使えます（`{min}` `{time}` は、読み間違いのないよう かなの読みに直して入ります）。
新しいセリフの種類は `src/phrases/types.ts` の `PHRASE_KEYS` に足して、全キャラのファイルに書きます（書きわすれるとビルドでエラーになります）。
アプリの ⚙️ せってい →「ためしにきく」「テストさいせい」で、読み間違いがないか確認できます。

## 入力欄と iPad / iPhone の注意（キーボードが出ない問題）
iOS では、入力欄（input・textarea・select）まわりに次があると、**キーボードが出なくなる**ことがあります。特に **ホーム画面に追加したアプリ（standalone）** で起きやすいです。
- 入力欄や その祖先に `user-select: none` / `-webkit-touch-callout: none` / `touch-action: none` / `pointer-events: none`
- 入力欄を `preventDefault` するイベント処理や、ドラッグ部品（dnd-kit）の中の入力欄
- 入力欄の祖先に `position: fixed` / `sticky`・`transform`・`overflow: hidden/auto`・`100vh`・`overscroll-behavior` などがある（重ね合わせのダイアログ、二重スクロール、全画面レイアウト）
- viewport の `user-scalable=no` / `maximum-scale`

そのため:
- ダイアログ（`src/components/Modal.tsx`）は、画面の上に重ねず、**ふつうの全画面ページ**として表示します（ひらいている間、うしろのよてい画面・ドラッグ部品はありません。閉じるとスクロール位置が戻ります）。ふかいダイアログ（どだい・じこくカード編集・しんだん）は、親の画面と入れかえて開きます
- `html` / `body` には `user-select: none` をかけず、さわって操作する部品だけにかけます。入力欄は `user-select: text` / `touch-action: manipulation` と明示
- ドラッグは `src/dndSensors.ts` の `SafeMouseSensor` / `SafeTouchSensor` が、入力欄・label・`data-no-drag` の上では はじめません
- `src/inputs.test.tsx` が、実際の画面の入力欄と その祖先を しらべます（上の項目すべて）。入力欄を足したときも `npm test` で自動チェックされます
- ⚙️せってい →「🛠 もじが いれられない とき（しんだん）」: 入力欄を ためして、タッチ・フォーカス・キーボードのログ（standaloneか、Service Worker、画面サイズ、バージョン）を コピーできます。実機で 起きたときの原因さがしに 使います

## あたらしい バージョンが とどくしくみ（PWA）
ホーム画面のアプリは、画面を端末にキャッシュ（Service Worker）してすぐ開きます。iOS のホーム画面アプリは Service Worker の更新が遅く、公開しても古い画面のままになることがあるので、`src/updates.ts` が **2とおり**で確かめます。
- Service Worker の更新（`registration.update()`、切りかわりは `controllerchange`）
- `version.json`（ビルドのたびに公開。キャッシュを使わず取りにいき、いまの版より日時が新しいか比べる）
- あたらしい版と分かったら、**開いて15秒以内なら、Service Worker とキャッシュをすてて自動で よみこみなおし**、それ以外は画面の上に「🔄 あたらしい バージョンが あるよ［こうしんする］」を出す（そうさ中に とつぜん消さない）
- しらべるタイミング: アプリを開いたとき・画面にもどったとき・30分ごと
- **版の番号**: 画面の下と ⚙️せってい に「バージョン（ビルドの日時とコミット番号）」を表示。⚙️せってい →「あたらしい バージョンを さがす」「がめんを よみこみなおす」もあります
- きろく・よてい・設定は localStorage にあるので、よみこみなおしても きえません
- 古い版のままに見えるとき: ホーム画面のアプリを一度完全に閉じて（アプリの切りかえ画面で上へスワイプ）開き直す

## 公開（GitHub Pages）
1. GitHub の **Settings → Pages → Source** を **GitHub Actions** にする（最初の1回だけ）
2. `main` に push すると `.github/workflows/deploy.yml` が自動でビルド＆デプロイ
3. `https://<ユーザー名>.github.io/jikan-app/` を iPad/スマホの Safari で開き、共有 →「ホーム画面に追加」

リポジトリ名を変えたら `vite.config.ts` の `REPO_NAME` も変えてください。

## アイコンの作り直し
`public/favicon.svg` を編集して `CHROMIUM_PATH=<chromiumのパス> npm run icons`。
