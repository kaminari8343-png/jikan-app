# きょうのよてい（jikan-app）

小学生が、帰宅後のスケジュールを自分で並べて、音声ガイドつきで実行するための PWA です。
React + Vite + TypeScript / データは localStorage に保存。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173/jikan-app/
npm test         # 時間計算・読み上げ(かな)のテスト
npm run build
```

## まいにちの土台（がっこうの日・やすみの日）
- **がっこうの日 / やすみの日**: 月〜金は「がっこうの日」、土日と日本の祝日は「やすみの日」。祝日は `@holiday-jp/holiday_jp` のデータをアプリに同梱しているので、ネット接続なしで判定します。
  長いお休み（なつやすみ など）は、⚙️せってい →「どだいと ながい やすみ」で期間を登録できます。その日だけ手動で「やすみに する／がっこうに する」も切りかえられます（優先順位: 手動 > 長いお休み > 祝日 > 土日 > 平日）
- **土台（テンプレート）**: その日に初めて開くと、その日の土台のじこくカードが自動で並びます。
  - がっこうの日: おきる 6:30 → あさのカード（きがえ・あさごはん・はみがき・トイレ・もちものチェック）→ いえをでる 7:20 → がっこう 7:20〜15:00 → ゆうごはん 18:30〜19:00 → おふろ 19:30〜20:00 → ねる 21:00
  - やすみの日: あさごはん 7:30〜8:00、ひるごはん 12:00〜12:30、ゆうごはん、おふろ、ねる
  - ⚙️せってい →「どだいと ながい やすみ」で、時刻・カード・曜日ごとの上書き（例: 水曜はがっこう 7:20〜14:00）を親が編集できます
  - 土台を直したり長いお休みを登録しても、すでに作られた日のよていは そのままです（種類が変わったときは「どだいで つくりなおす」を案内します）
- **あした**: 「あした」タブで、次の日のよていを前の晩に立てられます（スタートは当日から）。日がかわると、作っておいたよていが「きょう」になります
- **しずか（🔕）**: オンのじこくカードは、はじまり・おわりのお知らせをしません（5分前のお知らせはします）。がっこう・ごはん・おふろが初期でオン
- **いえをでる（🚪 でかけるカード）**: 10・5・1ぷんまえに「あと◯ぷんで いえをでるよ」、時刻に「いってらっしゃい！」
- **時刻だけのカード**（おきる・いえをでる）: 長さがなく、時刻になると知らせて すぐ次へ進みます
- 過ぎた時刻のじこくカードは うすく表示。スタートより前に過ぎたブロックのカードは、記録せずに とばします（夕方にスタートしても、朝の分が「じかんぎれ」にならないように）

## 1日のスケジュール（じこくカード・じゆうじかん）
- 📌 **じこくカード**: 開始時刻が決まっているカード（ゆうごはん 6じ30ぷん・おふろ・ねる など）。⚙️せってい →「じこくカード」で、親が追加・編集・削除できます（ねる は「ながさなし」＝1日の終わり）。
  よていの中では時刻順に自動で並び、ドラッグでは動かせません（✕で外せます）
- **あいだのブロック**: スタート時刻（初期値は「いま」、−／＋で変更）から最初のじこくカードまで、じこくカードどうしのあいだが1つのブロックです。
  ふつうのカードはブロックに積み、あまった時間は自動で「🕊️じゆうじかん」になります。入りきらないときは赤く「〇〇に まにあわないよ」と出ます
- **じっこう中**: ふつうのカードが早く終わったら、じこくカードの時刻まで「じゆうじかん」。時刻になったら、実行中のカードを止めて知らせ、⭕️❌をつけます。
  そのブロックでやれなかったカードは「じかんぎれ」として記録し、次のブロックへ進みます。「+5ふん」は次のじこくカードをこえるときはできません（理由を声で伝えます）。5分前にも知らせます
- **時計**: 文字盤に、予定ごとの色の扇形を表示（実行中は、いまのカードを強調）
- **りれき・はなまる**: じこくカード・じゆうじかん・じかんぎれも記録しますが、評価なし・はなまるの判定には入りません
- 「いつものよてい」には、じこくカードとスタート時刻も保存されます
- スタート時刻を「いま」以外にしても、じっこうは「いま」からはじまります（じこくカードの時刻はそのまま）

## りれき・じぶんでふりかえり
- カードの時間が終わると「⭕️／❌」の画面になり、押すまで次のカードは始まりません（スキップしたカードも評価できます）
- 「りれき」で、月ごとのカレンダーと、日ごとの記録（時刻順）が見られます
- 花丸💮: その日をさいごまでやって全部⭕️ / 丸⭕: さいごまでやったが❌が混ざった / 印なし: とちゅうでやめた
  （1日に何回かスタートした日は、全部の回を合わせて判定。何も評価しないうちにやめた回は数えません）
- 記録は localStorage（`jikan-app:history`）に保存。⚙️せってい →「きろくを ほぞん／よみこむ」でJSONバックアップ

## セリフを変える
`src/phrases.ts` だけ編集します（`{name}` `{min}` `{next}` が使えます）。
アプリの ⚙️ せってい →「テストさいせい」で、読み間違いがないか確認できます。

## 公開（GitHub Pages）
1. GitHub の **Settings → Pages → Source** を **GitHub Actions** にする（最初の1回だけ）
2. `main` に push すると `.github/workflows/deploy.yml` が自動でビルド＆デプロイ
3. `https://<ユーザー名>.github.io/jikan-app/` を iPad/スマホの Safari で開き、共有 →「ホーム画面に追加」

リポジトリ名を変えたら `vite.config.ts` の `REPO_NAME` も変えてください。

## アイコンの作り直し
`public/favicon.svg` を編集して `CHROMIUM_PATH=<chromiumのパス> npm run icons`。
